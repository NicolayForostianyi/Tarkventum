Tarkventum — офлайн-пакет
========================
Требуется Node.js 18+.

Запуск:
1) Распакуйте архив
2) cd Tarkventum
3) npm start
   (npm install не нужен — node_modules уже внутри)
4) Откройте http://localhost:3000

После обновления файлов из архива перезапустите сервер (Ctrl+C, затем снова npm start).

Данные:
- Аккаунты, ЛС и личный Канбан: data/*.json
- Комнаты (холст, стрелки/картинки, канбан комнаты, чат): data/rooms/<код>.json
  Комнаты сохраняются на диск и не пропадают после простоя / отключения.

Ручное редактирование файлов комнат (data/rooms/<код>.json):
- Лучше всего ОСТАНОВИТЬ сервер (Ctrl+C), отредактировать файл и запустить снова.
  Работающий сервер держит комнату в памяти и при любом изменении в комнате
  перезаписывает файл. Если в комнате никого нет, сервер сам перечитает
  изменённый файл при следующем входе.
- Имя файла = код комнаты. Экспорт JSON (кнопка «Экспорт JSON») тоже можно
  положить сюда — переименуйте его в <код>.json.
- Если файл сломан (лишняя запятая и т.п.), сервер НЕ затирает его: он
  переименовывается в <код>.json.broken-<время>.bak, а в консоли пишется ошибка.
  Исправьте файл и верните ему имя <код>.json (при остановленном сервере).
- Импорт: кнопка «Импорт» принимает файл «Экспорт JSON». Фигуры можно добавить
  или заменить; сообщения чата и карточки канбана добавляются (ничего не удаляется).
- Загрузки изображений: data/uploads/
- Аватары: data/avatars/

В этом пакете: стрелки с подписями и меню стиля (наконечники / пунктир),
сохранение комнат на диск, несколько вкладок комнат, личный и общий Канбан,
чат, ЛС, уведомления, ссылки на комнаты.
