Tarkventum — офлайн-пакет
========================
Требуется Node.js 18+.
1) Распакуйте архив
2) cd Tarkventum
3) npm start
Откройте http://localhost:3000
npm install не нужен — node_modules уже внутри.

В архиве доступны последние возможности: несколько вкладок комнат, личный и общий Канбан, чат комнат, ЛС, браузерные уведомления, ссылки на комнаты и фирменные фавиконы/логотипы.
