# Tarkventum

Локальное веб-приложение: совместный холст (whiteboard) + Канбан + чат в реальном времени.

Стек: **Node.js**, **Express**, **Socket.IO**, клиент на ванильном HTML/CSS/JS (Canvas API).

## Возможности

- Комнаты: создать или войти по коду / ссылке `/r/:roomId`
- **Вкладки комнат**: несколько комнат в браузерных вкладках приложения, переключение с leave/join по Socket.IO
- **Холст**: панорама, зум, перо, фигуры (прямоугольник, квадрат, круг, эллипс), BPMN-подобные (задача, шлюз, событие), линия/стрелка, **соединители** между фигурами, стикер, текст и **ссылка на комнату** (`roomLink`)
- Выделение с подсветкой при наведении, перемещение, ресайз, удаление (Delete/Backspace)
- **Inline-редактирование** текста/стикеров/подписей по двойному клику (Enter/blur — сохранить, Escape — отмена; без `prompt`)
- **Ссылка на комнату** (↗): фигура с кодом комнаты и заголовком; двойной клик открывает комнату во вкладках; Alt+двойной клик / Enter при выделении — правка; участвует в соединителях как обычная фигура
- Синхронизация объектов, соединителей и курсоров участников
- **Канбан на весь экран**: равная ширина колонок, добавление колонок (+), карточки с заголовком, описанием и сроком; цвет срочности; боковая панель редактирования
- **Темы**: чёрная, белая, зелёная, синяя (`localStorage`)
- Запоминание имени пользователя (`localStorage`)
- **Чат** комнаты (история до ~100 сообщений)

## Установка

Требуется Node.js 18+.

```bash
cd Tarkventum
npm install
```

## Запуск

```bash
npm start
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

Порт: `PORT=8080 npm start`

## Как проверить коллаборацию

1. `npm start`, две вкладки браузера на `http://localhost:3000`.
2. Создайте комнату в первой; откройте ссылку `/r/код` во второй.
3. На **Холсте** нарисуйте фигуры и соедините их инструментом ⟷ — у второго участника всё появится; двигайте фигуры — стрелки обновятся.
4. Двойной клик по стикеру/тексту — inline-редактор.
5. Инструмент **↗ «Ссылка на комнату»**: кликните на холст, укажите код другой комнаты; соедините стрелками с обычными фигурами; двойной клик — переключение вкладки / join.
6. **Канбан**: добавьте колонку, карточку со сроком — цвет меняется ближе к дедлайну.
7. Смените тему в шапке; перезагрузите — тема и имя сохранятся.
8. «+» на панели вкладок — откройте вторую комнату без полной перезагрузки UX.

## Ограничения

- Состояние комнат только в памяти (пропадает после перезапуска сервера).
- Нет аутентификации и паролей на комнаты.
- Соединители — прямые линии с наконечником (не ортогональные ломаные).
- Ссылка на комнату не проверяет существование целевой комнаты заранее — комната создаётся при входе; код нормализуется как при join (`a-z0-9_-`).
- Пустые комнаты удаляются примерно через 5 минут после ухода всех участников.
