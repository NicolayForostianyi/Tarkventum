# Tarkventum

Локальное веб-приложение: совместный холст (whiteboard) + Канбан + чат комнаты + личные сообщения в реальном времени.

Стек: **Node.js**, **Express**, **Socket.IO**, **bcryptjs**, **jsonwebtoken**, клиент на ванильном HTML/CSS/JS (Canvas API).

## Возможности

- **Аккаунты**: регистрация и вход (логин + пароль), пароли хешируются bcrypt, пользователи в `data/users.json`
- Сессия: JWT в `localStorage`; без входа приложение недоступно
- Комнаты: создать или войти по коду / ссылке `/r/:roomId` (имя в комнате = отображаемое имя аккаунта)
- **Вкладки комнат**: несколько комнат, переключение leave/join по Socket.IO
- **Холст**: панорама, зум, перо, фигуры, BPMN-подобные, соединители, стикер, текст, **ссылка на комнату** (`roomLink`)
- **Канбан**: два режима — **Мой канбан** (личный, на диске в `data/personal-kanban.json`) и **Канбан комнаты** (общий в комнате); переключение вкладкой/иконкой 👥
- **Темы**: чёрная, белая, зелёная, синяя
- **Чат комнаты** (история до ~100 сообщений в памяти)
- **Личные сообщения (ЛС)**: список пользователей, 1:1 переписки, сохранение в `data/dms.json`, бейдж непрочитанных, индикатор «в сети»
- **Браузерные уведомления**: о новых сообщениях чата/ЛС, когда вкладка в фоне или диалог не в фокусе; кнопка «Уведомления»

## Установка

Требуется Node.js 18+.

```bash
cd Tarkventum
npm install
```

## Запуск

```bash
npm start
```

Откройте: [http://localhost:3000](http://localhost:3000)

Порт: `PORT=8080 npm start`

Опционально: `JWT_SECRET=...` для подписи токенов (по умолчанию — dev-секрет).

## Как проверить

1. `npm start`, две вкладки (или два браузера) на `http://localhost:3000`.
2. Зарегистрируйте двух пользователей, войдите.
3. Создайте комнату в первой вкладке; во второй откройте `/r/код` после входа.
4. Проверьте холст, Канбан, чат комнаты.
5. Откройте вкладку **ЛС**, напишите друг другу — сообщения сохраняются после перезапуска сервера.
6. Нажмите **Уведомления** и разрешите permission; сверните вкладку и отправьте сообщение — появится уведомление.

## API (кратко)

- `POST /api/register` `{ username, password, displayName? }` → `{ token, user }`
- `POST /api/login` `{ username, password }` → `{ token, user }`
- `GET /api/me` (Bearer) → текущий пользователь
- Socket.IO: `auth: { token }`; события `dm-list-users`, `dm-get-thread`, `dm-send`, `dm-mark-read`, `dm-message`, `chat-message`, …
- Личный канбан: `personal-kanban-state`, `personal-card-*`, `personal-column-*`, `personal-cards-reorder` (только сокетам владельца)

Логин: 3–24 символа, `a-z`, `0-9`, `_`. Пароль: от 6 символов.

## Ограничения

- Комнаты (холст, Канбан, чат комнаты) сохраняются в `data/rooms/<код>.json`; аккаунты, ЛС и личный канбан — в `data/*.json`.
- Файлы комнат редактируйте при остановленном сервере (работающий сервер перезаписывает файл из памяти; пустую комнату он перечитает с диска сам). Экспорт JSON совместим с форматом файла комнаты (переименуйте в `<код>.json`). Повреждённый файл не затирается, а переименовывается в `*.broken-<время>.bak`.
- Соединители — прямые линии с наконечником.
