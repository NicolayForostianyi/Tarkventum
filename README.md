# Tarkventum

Локальное веб-приложение: совместный холст (whiteboard) + Канбан + чат в реальном времени.

Стек: **Node.js**, **Express**, **Socket.IO**, клиент на ванильном HTML/CSS/JS (Canvas API).

## Возможности (MVP)

- Комнаты: создать или войти по коду / ссылке `/r/:roomId`
- **Холст**: панорама, зум, перо, фигуры, линия/стрелка, стикер и текст; выделение, перемещение, удаление
- Синхронизация объектов и курсоров участников в реальном времени
- **Канбан**: колонки «Бэклог», «В работе», «Готово»; карточки; drag-and-drop; живая синхронизация
- **Чат** комнаты (история до ~100 сообщений для новых участников)
- Русский интерфейс

## Установка

Требуется Node.js 18+.

```bash
cd Tarkventum
npm install
```

## Запуск

```bash
npm start
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

Порт можно сменить: `PORT=8080 npm start`

## Как проверить коллаборацию

1. Запустите сервер (`npm start`).
2. Откройте две вкладки (или два окна / два браузера) на `http://localhost:3000`.
3. В первой вкладке введите имя и нажмите **Создать комнату** (или укажите код и **Войти**).
4. Скопируйте ссылку кнопкой **Ссылка** (или возьмите URL вида `/r/код`) и откройте её во второй вкладке — введите другое имя.
5. На **Холсте** нарисуйте фигуру — она появится у второго участника; двигайте курсор — видны чужие курсоры и имена.
6. Переключитесь на **Канбан**, добавьте карточку и перетащите между колонками — изменения синхронизируются.
7. В панели **Чат** отправьте сообщение (Enter или «Отправить») — оно видно всем; новый участник получит историю при входе.

## Ограничения MVP

- Состояние комнат только в оперативной памяти (после перезапуска сервера данные пропадают).
- Нет аутентификации и паролей на комнаты.
- Нет персистентного хранения файлов / экспорта в PDF или изображения.
- Текст и стикеры редактируются через `prompt` (простое MVP).
- Пустые комнаты удаляются примерно через 5 минут после ухода всех участников.
